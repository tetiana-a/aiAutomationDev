O projektu

Zadání a přístup

Zadání: HTML stránka s jedním inputem, zadám klíčové slovo a dostanu organické výsledky z 1. strany Google ve strojově čitelném formátu, pokrytí unit testy, nasazení na internet a volitelně Docker Compose.

Přístup: Google blokuje jednoduché stahování z cloudových serverů CAPTCHOU a oficiální Custom Search API je pro nové zákazníky uzavřené, proto data přicházejí přes SERP API za vyměnitelným rozhraním. Vše ostatní — filtrování, normalizace, export, testy a nasazení — je můj vlastní kód.

Stejná data uložíte jako JSON nebo CSV; CSV se správně otevře v Excelu i s diakritikou.

Funkce

Co umí

Jen organické výsledky

Reklamy, místní výsledky, „Lidé se také ptají“ a znalostní panel se vyřadí; duplicity a neplatné URL pryč, pozice 1…n.

Export JSON a CSV

CSV podle RFC 4180 s UTF‑8 BOM pro Excel a ochranou proti CSV injection.

Odkazy Google /goto

Od srpna 2026 Google skrývá část odkazů za google.com/goto; aplikace zjistí skutečný cíl, s bezpečnou zálohou.

Vyměnitelný zdroj dat

Rozhraní SerpProvider se dvěma implementacemi — SerpApi a Serper.

Cache a rate limit

Cache na 10 minut, takže zobrazení i stažení stojí jeden dotaz na API; 60 požadavků za 15 min z jedné IP a jasné chybové kódy.

Unit testy

61 testů ve Vitestu a Supertestu bez přístupu k síti; CSV načte zpět nezávislý parser a musí sedět.

E2E a přístupnost

Playwright na 9 zařízeních od iPhonu SE po 1920 px, kontrola axe‑core podle WCAG 2.2 AA v obou motivech, ovládání klávesnicí.

Design a rádio

Světlý a tmavý zlatý motiv, animované pozadí v Canvasu, tekuté sklo, rádio (ČRo Jazz a D‑dur, Radio Paradise, generativní ambient), které hraje až po kliknutí.

Stack

Architektura

Na serveru Node.js 22, TypeScript a Express 5; stránka v čistém HTML, CSS a JavaScriptu. Docker Compose pro lokální vývoj, testy v GitHub Actions, každý push do main se sám nasadí na Vercel. API klíč je jen v proměnných prostředí Vercelu — nikdy v kódu.
